Interface versus implementation. The interface is visible — the requests clients may make. The implementation is hidden — the code that actually performs each service. Concrete story: a music player app replaced its codec entirely, and the play button never moved. That is the payoff in the caption: change the core, and the shell stays, so clients never notice. A C pointer hands you the steering wheel; a Java reference only lets you point — details in chapter two. If you have written C, here is the map swap you must make.
