Three regions. Registers sit inside the CPU — not your business. The stack holds method-call frames and local variables: main calls f, f calls g, and each frame carries its own slots, like int x. The heap is where all objects live. Static storage exists for the whole run. The exam asks this as a short answer: where does each kind of variable live? Say heap with one clean vowel. The stack stores small fixed-size values — the eight primitives.
