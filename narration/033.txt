Rapid fire — four questions, mini-whiteboards, about ninety seconds each, answers chorus-style. One: s1 == s3 on two new Strings — false. Two: int x = 3.99 — does it compile? No, lossy conversion. Three: "grade code = " + 'A' + 1 prints grade code = A1. Four: while i less than five with a stray semicolon — empty body, the loop does nothing. Then Lab 3, the operator trap-hunt: five buggy snippets, B1 to B5 — find each bug, explain it, fix it. Bitwise, shift, and sizeof are self-reading; at most one multiple-choice question on them. You can compute — now make the program DECIDE.
