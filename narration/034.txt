Truth in Java is a type, not a number — conditions MUST be boolean, full stop. Here is C's famous bug, fixed by design: in C, assignment inside a condition compiled silently, so if x = 5 assigned five instead of comparing. Java refuses — int cannot be converted to boolean. The same trap wears another coat in Lab 3 as B5, boolean ok = (a = 5). Today we build if, if-else, and else-if chains — and the attitude matters as much as the syntax: readability first, guard clauses beat nesting. The cleanest if-else is the one that leaves early.
