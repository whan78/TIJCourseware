For each — the loop that hands you every egg, no index. You get the ELEMENT, never the INDEX, so there is no counter to get wrong. Live-code pause: convert the for loop on screen to foreach with me, then ask — what did we lose? The index, and therefore the ability to skip or reorder by position. And the trap, clearly: assigning to v inside the loop changes only the local copy; the array never notices. Exam code writing. Three exits from a loop, three different doors — next.
