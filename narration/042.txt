Who initializes fields? In C you do it yourself, or else. Java answers differently: the constructor runs, always, before you can touch the object. A constructor carries the same name as its class and has no return type at all — and watch the trap: if you write void CtorChain with empty parentheses, the compiler sees an ordinary method, not a constructor. Think of the constructor as a birth-certificate clerk: no object leaves the office unregistered. Remember the stamp picture from chapter two — fields start zero or null; the constructor is where the real values get guaranteed. One class can offer several ways to be born, and that is overloading, up next.
