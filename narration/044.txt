Overloading: same method name, different argument lists — you distinguish by the argument list only. The return type does not count; two methods differing only in return type will not compile. Resolution follows a ladder: an exact match wins first, then the smallest widening conversion — char to int to long to double — and varargs is the last resort. Picture the smallest mailbox the parcel fits into. Keep this contrast in your pocket: overloading changes the menu; overriding keeps the same order but cooks it a different way — the full comparison lands in chapter seven. The return-value rule is Know level. The vote is next — commit to a prediction first.
