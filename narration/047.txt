Two jobs, two spellings. this alone is a reference to the current object — "me". this with parentheses calls another constructor of the same class — "ask my colleague first". The chain here: the no-arg constructor calls this with unnamed and 0.0, the String version calls this with name and 9.99, and everything lands in the two-argument constructor where the real work happens. One absolute rule: this(...) must be the first statement in the constructor body. Put it anywhere else and the compiler says: call to this must be first statement in constructor. Read that error aloud with me. Now watch the chain in the real code.
