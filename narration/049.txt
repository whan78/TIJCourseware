The static initialization block runs exactly once, when the class loads — not once per object. The top lane is the class lane: one crossing at class load, the static block fires, the static field box is created. The bottom lane is the object lane: every new fires its own burst — instance fields first, then the constructor body — and the class-lane line is never crossed again. One verified error to burn in: call a non-static method from main and you get: non-static method X cannot be referenced from a static context. The reflex: no object yet — create one first. finalize mechanics and enum depth stay in self-reading; the exam weight there is a single question.
