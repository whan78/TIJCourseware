Garbage collection reclaims objects that no live reference can reach. Reachable means someone still aims an arrow at you. Look at the graph: the main root reaches the chain through references a, b and c — every one of those objects has a path from a live reference. The island is different: two objects pointing only at each other. No path from any live reference, so both are collectable. Quick poll: which object can GC collect — point at the island or at the chain? And remember, you never free memory yourself; there is no free() in Java. finalize exists but is unreliable — never plan around it. But GC only reclaims memory.
