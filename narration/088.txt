Downcasting: a base reference narrowed to a derived type. Up the tree is always safe — green. Down the tree, Java checks at run time, and it may fail — that is the cliff edge, ClassCastException. Why check at run time? Because the compile-time reference type cannot know the real object; RTTI is how it knows — run-time type information, read letter by letter. instanceof is the guard rail before the cliff: test first, cast second, and the safe path goes around the edge.
