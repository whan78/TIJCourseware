The last pattern answers: who gets to say new? A Factory is an interface whose implementations create objects. The client asks the factory for a Shape and never writes the concrete class name — see the crossed-out ghost new Circle() on the client. The only new in the whole codebase lives inside the fenced corner, inside the factories. Add a Triangle later, and the client still compiles untouched. This is a required project element: the product is the object seen through its interface.
