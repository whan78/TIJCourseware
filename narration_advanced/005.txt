Here is the one idea the whole chapter rests on. When you instantiate an inner class, the resulting object silently carries a reference to the outer object that created it. The compiler inserts it; you never write it. That reference is why an inner class can read private outer fields — look at dest() touching contents directly. And it is why you cannot build a standalone inner object: there would be nothing to point at. In C++ a nested class is just a scoping convenience with no such link; in Java the link is the feature. Ask yourself as we go: who owns this hidden reference?
