This is the pattern that justifies inner classes. The private inner SequenceSelector implements Selector, and selector() returns only the interface — clients upcast without knowing any concrete name. End, current, and next read the private array of the outer Sequence directly; with a top-level class we would need accessor methods or fields we did not want to expose. Second benefit: since the selector must remember which sequence it walks, keeping state in an object — an iterator object — is natural.
