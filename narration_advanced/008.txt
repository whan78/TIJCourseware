The anonymous inner class is the workhorse idiom of this whole course part. Read the syntax aloud: new Contents, open brace, body, close brace — and since it is an expression, the semicolon. Inside the braces you are writing a class body: fields, initializers, methods — everything except a constructor, because there is no name to give it. The instance initializer clause is therefore how you do constructor-like work. Note the final parameter: the object escapes the method, so captured locals must be final. With an actual class instead of an interface, arguments in the parentheses go to that class constructor.
