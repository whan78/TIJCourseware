Now the contrast that the exam loves. Add static and the hidden link disappears: a nested class is just a class that happens to be written inside another one, for scoping and packaging. It cannot touch outer instance state, and you build it without any outer object — new Outer.Nested. Compare the two creation lines at the bottom. Classes inside interfaces are implicitly public and static — remember that when we meet builders in later libraries. Practical rule: reach for static unless you can point at the outer instance member you need.
