Memorize this slide and half the chapter organizes itself. Collection is the root for individual elements; under it sit List, which promises sequence and accepts duplicates; Set, which refuses duplicates; and Queue, which orders by arrival or priority. Map is deliberately separate — it is not a Collection — because key-value is a different shape of thinking; you will still get collection views of keys and values when you need iteration. When you meet any new container class in the library, your first question is: which branch of this tree is it on?
