Before touring the families, the small print about getting elements INTO containers. Arrays.asList looks like a convenience — and it is — but the list it returns is fixed size, backed by the array: set works, add throws UnsupportedOperationException. That surprises people in exams and in production. Wrap it in a real ArrayList when you need growth. And remember Collections.addAll as the fastest bulk append. Predict line by line which calls compile and which throw — this snippet is a classic exam code-reading item.
