A Set refuses duplicates — the interesting question is how each implementation decides same and different, and what order you get out. HashSet uses hashing: constant-time contains, but iteration order looks like noise. TreeSet keeps everything sorted, at logarithmic cost, so it needs the elements comparable. LinkedHashSet threads a list through the hash table so iteration follows insertion while staying fast. All three judge duplicates through equals and hashCode — the elements themselves carry that logic, which is exactly where chapter seventeen picks up.
