Maps associate keys with values, and every method follows from that: put stores, get fetches, containsKey tests. Watch the fifth line — putting under an existing key silently replaces the previous value; that is a favorite exam trap. For traversal you get three live views: keys, values, and entries. Note the third loop pattern: iterating entrySet gives you key and value in one step, instead of paying a second hash lookup for every get inside the loop. HashMap iterates in hash order; swap in TreeMap and the same code prints sorted by key.
