Why exceptions exist, in one contrast. On the left, error codes: every single call site must remember to check, and the one place a developer forgets becomes a silent, delayed failure. On the right, the exception path: the try block reads like the happy path — open, read, process — and all the error handling gathers into catch blocks. Throw creates an exception object; the runtime unwinds the call stack until a matching catch accepts it. Nothing is silently dropped: an uncaught exception terminates the program with a printed trace. That loudness is a feature.
