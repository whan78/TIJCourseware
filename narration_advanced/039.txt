One property explains the whole chapter: strings are immutable. Method calls like toUpperCase do not touch the receiver — they return a brand-new string, and if you ignore the return value the work evaporates, which is the number-one beginner bug. Immutability also makes aliasing harmless: two references sharing one string is safe precisely because neither can edit it. But then == tests reference identity, not text — equals is the comparison you almost always want. Interning may make two literals the same object; never lean on that for logic.
