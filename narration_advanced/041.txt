Two quirks, both from the same root: printing an object calls its toString. First, the unconscious recursion — inside toString you concatenate this, which silently calls toString again, forever; the stack overflows. The fix is to print fields or call the Object version explicitly. Second, raw arrays do not print contents — you get the internal type signature and identity hash, which looks like garbage but is honest output; Arrays.toString is the right tool. Both traps appear in exam options because both appear in real code reviews weekly.
