The motivating picture. You upcast shapes into a list, and the static type system now sees only Shape. Drawing works through dynamic binding — no type information needed. The moment you need a Circle-only operation, though, you must ASK the object what it is, and the answer lives in the Class object every object carries — its runtime fingerprint. instanceof tests it; the cast then unlocks the Circle interface. Notice the shape of good code: polymorphism first, RTTI only where subtypes genuinely differ. Sprinkling instanceof everywhere is a design smell, and the book says so plainly.
