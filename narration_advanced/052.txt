The conceptual split. RTTI works when the class is part of your program at compile time — instanceof, cast, call, with the compiler watching. Reflection works when the class arrives at run time — a name from a config file, a plugin, a test class — and the program must discover its constructors and methods and invoke them blind. Read the snippet: it is a minimal JUnit — load whatever class the user named, instantiate, and invoke every method starting with test. Powerful, but unchecked and slow: reflection is framework machinery, and reaching for it inside ordinary application logic is usually a design mistake.
