The design lesson the chapter ends on. A cascade of instanceof grows linearly with subtypes and touches every place it is copy-pasted. The registry pattern inverts it: every Part subclass registers a factory object into a shared map inside its static initializer — the class-load hook from earlier in this chapter. Clients then create parts by identifier with no type test anywhere. Adding a FuelFilter is one class plus one registration; no existing code changes. Compare with the Chapter 9 factory and the Chapter 10 anonymous-factory version — same idea, increasingly automated.
