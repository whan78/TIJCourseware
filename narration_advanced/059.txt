Motivation in one contrast. The Object-based holder accepts everything, forces a cast on every read, and happily stores an Integer in a holder you mentally reserved for strings — the failure lands wherever the bad get happens. The generic holder takes its type as a parameter: set rejects the Integer at compile time and get returns String directly. One class definition, checked differently at every use site. This is exactly what List and Map were doing all along in chapter eleven — today you learn to build such APIs yourself.
