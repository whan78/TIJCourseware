Syntax, minimum viable. Declare the type parameter once after the class name, then use T like a real type everywhere inside. At the use site the angle brackets fix the meaning — and the diamond saves you from writing the argument twice. Two details worth marking: primitives are not allowed as type arguments, so an int becomes Integer with autoboxing; and multiple parameters are fine — the tuple at the bottom returns two typed values at once, with final fields making the pair safely immutable. You will use tuples in the lab to return statistics without dedicating a class per combination.
