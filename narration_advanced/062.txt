Varargs meets generics in one small factory method. The compiler packs the arguments into an array of T, and the inference rule spans the whole call: every argument must fit the ONE chosen T, so mixed types widen to their common supertype — Object if necessary. This is exactly the signature of Arrays.asList, which you have been using since chapter eleven; after this slide you can read its real declaration in the documentation without flinching. One footnote we return to on the limits slide: arrays of generics are themselves restricted, and varargs quietly creates one.
