One of the book's sharpest contrasts. Arrays covariant: an Apple array masquerades as an Object array, the wrong store compiles, and the JVM catches it at run time with ArrayStoreException — a full program crash discovered late. Generics chose the opposite trade: invariance, so the same mistake is refused at compile time, before the program ever runs. Connect this to erasure: since T vanishes, the runtime could not check generic array stores anyway — which is why new T bracket bracket is forbidden. Early failure is the theme of the entire chapter, stated in one code slide.
