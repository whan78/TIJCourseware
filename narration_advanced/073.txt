Two-dimensional arrays are just arrays of array references, which makes ragged shapes trivial: allocate the outer array, then give each row its own length. Watch the triangle print — row zero is empty because we allocated length one starting at index one. deepToString is the printing tool for any nesting depth; plain toString would print reference garbage, as chapter thirteen warned. One trap for the quiz: accessing a row before allocating it dereferences null — a NullPointerException, the unchecked family, as chapter twelve classified it.
