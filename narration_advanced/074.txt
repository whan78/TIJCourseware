Bulk operations you should reach for instead of hand loops. Fill comes in whole-array and range flavors with the half-open interval convention. Copying has three tools: copyOf with a target length — which is how you grow an array, padding with zeros; copyOfRange with the exclusive end; and System.arraycopy, the native five-argument mover, still the fastest path. One warning that returns in chapter seventeen: copying an object array is shallow — the new array holds the same references, so mutating an element mutates it everywhere.
