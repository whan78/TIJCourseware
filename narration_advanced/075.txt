Sorting splits by type: primitives sort by value, objects need an ordering — the natural one from Comparable, or any Comparator you pass, from reverse order to case-insensitive strings. Binary search is the two-edged tool: logarithmic speed, but only on sorted data — the last line of the slide is deliberately garbage because the input was unsorted. Learn the miss convention: negative of the insertion point minus one, which encodes exactly where the value would belong. That formula appears on exams with surprising regularity.
