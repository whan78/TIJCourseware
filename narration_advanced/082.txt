The most examinable ten lines of the chapter. Default hashCode is object identity, so two groundhogs with the same number hash to different buckets — the map looks them up in the wrong bucket and returns null even though an 'equal' key was stored. The fix is the PAIR: hashCode aligned with the equality definition, equals using instanceof and field comparison. Recite the contract — equal objects must have equal hash codes, unequal objects may collide harmlessly. And adopt the professional rule on the annotation slide: equals and hashCode ship together, always.
