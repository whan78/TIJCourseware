Performance tuning, honestly explained. A hash map holds its speed by staying sparse: when entries exceed capacity times load factor — twelve on the default sixteen — the table doubles and every entry is rehashed into new buckets. One such rebuild is linear and visible in latency spikes; a million-entry map built with defaults rebuilds repeatedly. The professional habit on the slide: pre-size with expected size over load factor. Mention the modern safety net — Java eight converts overlong buckets into trees — but keep the exam answer classical: O-one average under a bounded load factor.
