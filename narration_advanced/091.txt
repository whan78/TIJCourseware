File is the most misnamed class in the library: it represents a pathname, not the file's contents. The example lists a directory through a lambda filename filter — note the sorted output and the case-insensitive comparator from chapter sixteen. The second block is the diagnostics vocabulary: exists, length, canRead, renameTo, delete. Two habits to build early: File methods mostly return booleans rather than throwing, so uncheck results at your peril; and a File object may point at nothing — it is only an address until the filesystem disagrees.
