The forest becomes a map on two axes. Byte streams root at InputStream and OutputStream — machine-facing, eight bits at a time. Character streams root at Reader and Writer — text-facing, with a charset doing the byte-to-char translation, which is where every encoding bug you will ever meet is born. The bridge between worlds is InputStreamReader. Below each root sit the decorators we meet next: buffered, data, and object flavors. The output trees mirror the input trees class for class — learn one side and you own both.
