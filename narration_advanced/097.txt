The encoding slide — short, but it prevents years of mysterious bugs. The adapter classes are where bytes become characters, and they demand a charset: name it explicitly and the file means the same thing in every country; omit it and the platform default decides, which differs between machines. The second half is the process plumbing: System.in as the byte source, out and err as print streams — and the setIn redirection trick, which is how you will unit-test console-reading code against a file instead of typed input. Keep the explicit-charset habit from today onward.
