The everyday enum surface. Declaring Spiciness creates four constants — instances of the enum type — plus generated statics: values in declaration order and ordinal as the index. Note the switch: case labels are unqualified because the compiler already knows the switch expression's type; writing Spiciness.MEDIUM there is a compile error, a favorite trap. Printing an enum calls name, and compareTo follows declaration order. Everything else you might expect — valueOf by string, equals, hashCode — comes generated and correct. This page plus the next is the M-level core of the chapter.
