Pull back the curtain. The enum keyword compiles to a normal class extending Enum: your constants become public static final instances built once during class initialization, values returns a clone of the internal array — which is why calling it inside a loop is a quiet allocation bug — and every enum safety property falls out of this shape: == works because instances are singletons; you cannot add constants because the constructor is private and the array is fixed; serialization is safe for the same reason.
